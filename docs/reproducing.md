# Reproducing the results

## Environment

- **Lean** v4.28.0 with Mathlib v4.28.0, pinned in `lean/lean-toolchain` and `lean/lakefile.toml`.
- **Nothing else.** Every result is a Lean theorem; there are no scripts, numerical runs or certificate files to reproduce.
- **Build time.** With the prebuilt Mathlib cache, a full build of the library took 43 minutes on one Windows machine. The slowest modules take three to four minutes each.

## All three results

```
cd lean
lake exe cache get        # downloads prebuilt Mathlib
lake build
lake env lean AxiomCheck.lean
```

`AxiomCheck.lean` prints the axioms of every theorem cited in a `claims.md`: the main theorems of the three papers, their specialisations to Δ, and the named witnesses. Every one should be among `propext`, `Classical.choice` and `Quot.sound`, with no `sorryAx`. `scripts/setup-shared-deps.ps1` can instead point `.lake/packages` at a shared Mathlib store on Windows.

### The proof map

`lean/proofmap.html` is generated by [proofmap](https://github.com/n0zer0d4y/proofmap) (v0.3.1) from the compiled library, with the settings in `lean/proofmap.toml`. To regenerate it, install proofmap as its README describes, then:

```
cd lean
proofmap build      # runs lake build, then writes proofmap.html
proofmap check      # lists anything that depends on sorry or on a non-standard axiom
```
